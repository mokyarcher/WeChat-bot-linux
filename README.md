# 小鲸鱼 Linux 微信机器人

文档基线：2026-11-06。依据当前代码及最近部署验证整理，实时运行状态请查看服务。

本项目将微信与机器人业务部署在独立 Linux 环境，保留原项目的人设、记忆、人物关系和回复策略。

## 当前架构

```text
Docker 内官方 Linux 微信 4.1.1.8
  ↕ AT-SPI 读取可见控件；真实键鼠、剪贴板发送
bowxt：HTTP API、消息存储、单线程 UI 操作
  ↕ standalone：事件长轮询、格式与运行环境适配
mengyunqwq/wechat-bot：人设、记忆、回复策略和完整面板
  ↕ 模型适配
用户配置的模型服务（当前部署使用 DeepSeek）
```

未使用 Windows hook，也未接入 AWSL、Weixin Group AI Bot。运行时不需要 DSH 宿主。

| 目录 | 用途 |
|---|---|
| upstream/bowxt-main | Linux 接入源码，包含本地优化 |
| upstream/wechat-bot | 原业务与面板，包含排序、沉默判断及打字等待等本地补丁，并非原样副本 |
| standalone | 独立服务、模型适配、简易首页、部署模板与测试 |
| .runtime | 已忽略的本机私有凭据和临时脚本，不是通用安装入口，不应提交 |

上游自带文档描述各自原产品，不代表本组合部署已适配全部能力。

## 使用

- [设置首页](https://chat-manage.sharex.team/)：配置模型、测试连接、启用/暂停。
- [完整面板](https://chat-manage.sharex.team/wechat-bot)：人设、记忆、回复节奏及部分查询。
- [远程桌面](https://chat-manage.sharex.team/desktop/)：管理员密码 + 手机动态验证码，再输入独立 VNC 密码，无需 SSH 隧道。首页也提供入口。

手机首次绑定打开本机 `.runtime/小鲸鱼手机验证绑定.png` 用验证器扫描；VNC 密码见 `.runtime/远程桌面登录说明.txt`。这些文件是私有凭据，不要分享或提交。服务器已预置该 TOTP，手机扫码保存后才能日常登录；当前尚待用户扫码确认。

`连接云端微信.ps1` 保留作备用运维入口，隧道访问 VNC 同样需要独立 VNC 密码。

当前机器人“小鲸鱼”，监听群“小鲸鱼调教”，chat_id=1，业务房间 ID 为 bowxt:1@chatroom。服务重启后接入默认暂停，需要在首页重新启用。首次同步建立快照，不自动回复历史消息。改群名需同步监听配置，保留内部 ID 才能沿用原群记忆。

文字聊天、人设和记忆已接通；完整面板已提供 Linux 自检、群名维护、统一模型配置、核心对话/拆句参数、记忆归档恢复及当前群记忆快照恢复。快照恢复前需要暂停，且会保留恢复前副本。多媒体、朋友圈、原版升级等仍不可用。Linux 状态来自接入快照，客户端连接不等于证明账号登录。模型连接测试会实际调用配置的模型。

目前仅一个测试群；成员身份按群和显示名生成，同名、改名不能可靠自动识别，跨群记忆关闭。已上线 ACK 前轮次持久化与保守退出恢复：未完成轮次重启后进入待核查，不自动重放；按阶段自动续跑仍待补齐，属于试点版本。发布结果见部署维护文档。

完整面板“手动操作”已接通当前群纯文字发送、已记录消息分页、逐页关键词与首次接收日期匹配。日期按北京时间，结束日期含当天。发送需回复与接入均启用，确认后发送并等待回显。查询不包含接入尚未记录的微信历史；日期与关键词都仍需逐页向前查，不是全库一键搜索。

## 源码仓库与提交

代码仓库：https://github.com/mokyarcher/WeChat-bot-linux 。根仓库保存 Linux 适配层与包含本地补丁的上游源码快照；子目录原有 Git 元数据不上传，也不使用子模块替代源码。

提交前检查暂存文件，不上传 `.runtime/`、运行数据、微信登录卷、`soul-data/`、模型密钥、二维码、数据库、日志或备份。仓库不包含云端数据，克隆代码不能恢复线上登录、人设或记忆；这些数据不由 Git 恢复。配置请从示例创建。本地文档需随代码维护，云端更新不会自动同步本地文档。

维护规则（2026-11-06 更新）：以后修改或发布不再例行在云服务器创建代码、配置或数据备份；修改前先核对当前状态，尽量保留原启停状态。出现问题先询问用户，再决定是否从本地 Git 的指定提交回退代码，不自动回退或覆盖运行数据。面板既有的人格、记忆快照及恢复前保护保持原有行为。仓库不收录 Windows 发布二进制 `upstream/wechat-bot/release/version.dll`。

运维日志中的待核查轮次支持“核对发送结果”，只读查询每段回复的接入记录；未查到不判定为未发送，不自动补发。发布状态见部署维护。

安全等待阶段恢复：运维页对可证明尚在等待合并、最近 5 分钟内的异常中断文字任务显示“继续处理”；需启用后确认，最多一次。生成中、已发送或结果不确定的任务仍只能核查，不自动重放。

运维日志新增“运行记录容量”：查看轮次及发送映射数量、占用，暂停后可预览确认归档超过 30 天的已完成/已跳过轮次。完整原文压缩保留，去重能力保留；待核查、待处理和发送映射不清理，不自动执行。

本批联合适配：运维页提供最近 50 条消息的阶段耗时和不回复原因；文字设置补齐作息例外、回复字数、情境沉默与口语样式，并提供服务端生效值；群与人提供需暂停及预览确认的成员改名映射。仅影响后续身份解释，不自动合并历史关系、不开放跨群记忆。发布与验收说明见部署维护。

面板侧栏统一使用四字名称：运行总览、功能开关、回复节奏、主动行为、说话方式、表情图库、多模感知、语音交互、记忆空间、内心世界、关系星盘、群友管理、好友动态、人设模型、系统诊断、版本更新、运维日志、手动操作。仅调整显示名称，原页面标识、功能及数据不变。
